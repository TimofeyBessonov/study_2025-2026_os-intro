# **Теоретические сведения**

## **Менеджер паролей pass**

Менеджер паролей pass следует философии Unix:

> * Каждая запись представляет собой отдельный текстовый файл, зашифрованный с помощью GPG.  
> * Иерархия паролей повторяет структуру папок файловой системы (например, \~/.password-store/email/user@example.com.gpg).  
> * Поддерживается прямое управление через Git: каждое добавление или изменение пароля фиксируется атомарным коммитом.  
> * Семантика именования позволяет гибко разграничивать доступ к ресурсам: хост/пользователь.gpg, пользователь@хост:порт.gpg.

## **Управление dotfiles через chezmoi**

Утилита chezmoi управляет конфигурационными файлами пользователя:

> * Хранит целевое состояние в Git-репозитории в каталоге \~/.local/share/chezmoi.  
> * Позволяет использовать шаблоны Go template (файлы с расширением .tmpl) для генерации платформозависимых конфигов на основе переменных хоста (.chezmoi.os, .chezmoi.hostname).  
> * Разрешает версионирование прав доступа (например, режим chmod 600 для приватных ключей).  
> * Обеспечивает безопасное развёртывание конфигурации на новых машинах командой chezmoi init \--apply \<repo\_url\>.

# **Выполнение лабораторной работы**

## **1\. Установка и настройка менеджера паролей pass**

В терминале установили пакеты pass и расширение одноразовых паролей pass-otp:  
`sudo dnf install -y pass pass-otp`

Проверили наличие созданного ранее GPG-ключа (mamkar228@yandex.ru) и инициализировали хранилище паролей:  
`gpg --list-secret-keys --keyid-format LONG`  
`pass init mamkar228@yandex.ru`

Инициализировали Git-репозиторий внутри хранилища паролей и связали его с приватным репозиторием на GitHub:  
`pass git init`  
`pass git remote add origin git@github.com:trbessonov/pass-store.git`

Добавили тестовые записи и проверили генерацию стойких паролей:  
`pass insert study/rudn-portal`  
`pass generate -c services/github 24`  
`pass study/rudn-portal`

\!\[\[01-pass-init.png\]\] *Рис. 2\. Инициализация pass и генерация пароля*

## **2\. Настройка взаимодействия с браузером (browserpass)**

Для интеграции хранилища pass с веб\-браузером подключили репозиторий Copr и установили нативный интерфейс сообщений:  
`sudo dnf copr enable -y maximbaz/browserpass`  
`sudo dnf install -y browserpass`

Сконфигурировали системные хосты native messaging для браузеров:  
`sudo browserpass-bootstrap`

\!\[\[02-browserpass-setup.png\]\] *Рис. 3\. Настройка компонентов browserpass-native*

## **3\. Установка дополнительного ПО рабочего окружения**

Установили необходимые графические утилиты окружения Wayland/Sway и набор специализированных шрифтов:  
`sudo dnf -y install \`  
    `dunst fontawesome-fonts powerline-fonts light fuzzel \`  
    `swaylock kitty waybar swaybg wl-clipboard mpv grim slurp`

`sudo dnf copr enable -y peterwu/iosevka`

## **4\. Установка chezmoi и создание репозитория dotfiles**

Установили бинарный файл chezmoi с помощью официального скрипта загрузки:  
`sh -c "$(wget -qO- chezmoi.io/get)"`  
`sudo mv ./bin/chezmoi /usr/local/bin/`

С помощью CLI gh создали приватный репозиторий dotfiles на основе университетского шаблона:  
`gh repo create dotfiles --template="yamadharma/dotfiles-template" --private`

Инициализировали chezmoi с созданным удалённым репозиторием, проанализировали вносимые диффы и применили конфигурацию к домашнему каталогу:  
`chezmoi init git@github.com:trbessonov/dotfiles.git`  
`chezmoi diff`  
`chezmoi apply -v`

\!\[\[04-chezmoi-init.png\]\] *Рис. 5\. Первичная инициализация и применение dotfiles через chezmoi*

## **5\. Работа с шаблонами chezmoi и автоматизация синхронизации**

Освоили работу с шаблонизацией файлов на синтаксисе Go template. Проверили переменные окружения, доступные утилите:  
`chezmoi data`

Добавили файл конфигурации в виде динамического шаблона и проверили подстановку платформенных условий (if eq .chezmoi.os "linux"):  
`chezmoi add --template ~/.bashrc`  
`chezmoi execute-template '{{ .chezmoi.os }}/{{ .chezmoi.hostname }}'`

В локальном конфигурационном файле \~/.config/chezmoi/chezmoi.toml включили параметры автоматического создания коммитов и отправки в удалённый репозиторий:  
`[git]`  
    `autoCommit = true`  
    `autoPush = true`

Выполнили проверку синхронизации:  
`chezmoi edit ~/.bashrc`  
`chezmoi update -v`
