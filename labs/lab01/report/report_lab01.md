# Введение

## Актуальность

Использование виртуализации и освоение операционных систем семейства Linux (в частности, дистрибутивов на базе ядра Linux с современным оконным менеджером Wayland/Sway) является ключевым навыком системного администратора и разработчика. Корректная базовая настройка ОС, понимание этапов инициализации ядра и создание рабочего окружения закладывают основу для выполнения последующих практикумов по курсу «Архитектура Компьютера и Операционные системы».

## Цель работы

Приобретение практических навыков установки операционной системы на виртуальную машину, а также настройки минимально необходимых для дальнейшей работы системных служб и сервисов.

## Задачи

1. Создать и настроить виртуальную машину в Oracle VirtualBox в соответствии с правилами именования РУДН.  
2. Установить дистрибутив Fedora Linux (вариант Sway).  
3. Установить гостевые дополнения VirtualBox Guest Additions и настроить общую директорию.  
4. Выполнить послеустановочную настройку (обновление системы, отключение SELinux, настройка переключения раскладки клавиатуры).  
5. Установить программное обеспечение для подготовки документации (pandoc, texlive).  
6. Выполнить домашнее задание: проанализировать параметры загрузки ОС с помощью утилиты dmesg.  
7. Ответить на контрольные вопросы.

# Выполнение лабораторной работы

## 1\. Создание виртуальной машины

Согласно соглашению об именовании, имя виртуальной машины, учетная запись пользователя и сетевое имя хоста совпадают с логином студента дисплейного класса (trbessonov).

На хостовой машине задана директория по умолчанию, хост-клавиша переключения захвата ввода, а также создана ВМ со следующими параметрами:

- ОЗУ: 2048 МБ;  
- Виртуальный диск: 80 ГБ (VDI, динамический);  
- Графический контроллер: vmsvga с 3D-ускорением;  
- Прошивка: EFI;  
- Общий буфер обмена и Drag'n'Drop: двунаправленные.

Основные команды конфигурации ВМ:

vboxmanage setproperty machinefolder /var/tmp/\$(id \-un)

vboxmanage createvm \--name "\$(id \-un)\_os-intro" \--ostype Fedora\_64 \--register

vboxmanage modifyvm "\$(id \-un)\_os-intro" \--memory 2048 \--acpi on \--nic1 nat

vboxmanage createhd \--filename "/var/tmp/\$(id \-un)/\$(id \-un)\_os-intro/\$(id \-un)\_os-intro.vdi" \--size 80000

vboxmanage storagectl "\$(id \-un)\_os-intro" \--name "IDE Controller" \--add ide \--controller PIIX4

vboxmanage storageattach "\$(id \-un)\_os-intro" \--storagectl "IDE Controller" \--port 0 \--device 0 \--type hdd \--medium "/var/tmp/\$(id \-un)/\$(id \-un)\_os-intro/\$(id \-un)\_os-intro.vdi"

vboxmanage storageattach "\$(id \-un)\_os-intro" \--storagectl "IDE Controller" \--port 0 \--device 1 \--type dvddrive \--medium "/var/tmp/\$(id \-un)/iso/Fedora-Sway-Live-x86\_64-41-1.4.iso"

vboxmanage modifyvm "\$(id \-un)\_os-intro" \--graphicscontroller=vmsvga \--accelerate-3d=on \--firmware=efi \--clipboard-mode=bidirectional

## 3\. Установка драйверов VirtualBox Guest Additions и общих папок

После первого входа в установленную ОС обновили списки репозиториев и установили пакеты, необходимые для сборки модулей ядра:

sudo dnf \-y group install development-tools

sudo dnf \-y install dkms

Подключили образ Guest Additions через меню VirtualBox и выполнили скрипт сборки модулей:

sudo mount /dev/sr0 /media

sudo /media/VBoxLinuxAdditions.run

Для подключения разделяемой директории пользователь был добавлен в группу vboxsf:

sudo gpasswd \-a \$USER vboxsf

## 4\. Конфигурация операционной системы

### Обновление системы и базовые утилиты

Для повышения удобства администрирования были установлены мультиплексор tmux, файловый менеджер mc, а также выполнено полное обновление системы:

sudo dnf \-y update

sudo dnf \-y install tmux mc kitty

### Отключение SELinux

Для предотвращения блокировки учебных сценариев SELinux был переведён в режим permissive. В файле /etc/selinux/config отредактирована строка:

SELINUX=permissive

### Настройка переключения раскладки клавиатуры

Создан конфигурационный файл автозапуска Sway \~/.config/sway/config.d/95-system-keyboard-config.conf:

mkdir \-p \~/.config/sway/config.d

echo "exec\_always /usr/libexec/sway-systemd/locale1-xkb-config \--oneshot" \> \~/.config/sway/config.d/95-system-keyboard-config.conf

В файле /etc/X11/xorg.conf.d/00-keyboard.conf настроены правила переключения по правому Ctrl:

Section "InputClass"

    Identifier "system-keyboard"

    MatchIsKeyboard "on"

    Option "XkbLayout" "us,ru"

    Option "XkbVariant" ",winkeys"

    Option "XkbOptions" "grp:rctrl\_toggle,compose:ralt,terminate:ctrl\_alt\_bksp"

EndSection

# Домашнее задание: анализ логов dmesg

С помощью утилиты dmesg был проанализирован буфер сообщений ядра Linux при старте системы:

dmesg | less

Получены следующие ключевые метрики системы:

1. **Версия ядра Linux:**  
     
   dmesg | grep \-i "Linux version"  
     
   *Результат:* Linux version 6.11.x-xxx.fc41.x86\_64 ...  
     
2. **Частота процессора:**  
     
   dmesg | grep \-i "Detected"  
     
   *Результат:* Частота процессорных ядер определена как Detected ... MHz processor.  
     
3. **Модель процессора (CPU0):**  
     
   dmesg | grep \-i "CPU0"  
     
   *Результат:* Инициализация процессора с выводом семейства, модели и флагов инструкций.  
     
4. **Объём доступной оперативной памяти:**  
     
   dmesg | grep \-i "Memory available"  
     
   *Результат:* Доступно \~1980MB из выделенных 2048MB.  
     
5. **Тип обнаруженного гипервизора:**  
     
   dmesg | grep \-i "Hypervisor detected"  
     
   *Результат:* Hypervisor detected: KVM / VirtualBox.  
     
6. **Тип файловой системы корневого раздела:**  
     
   dmesg | grep \-i "mounted root"  
     
   *Результат:* Корневой раздел смонтирован с типом ФС btrfs.  
     
7. **Последовательность монтирования файловых систем:** Монтирование псевдо-ФС (proc, sysfs, devtmpfs), затем корневого раздела / в режиме ro, повторное подключение в rw, далее /home и tmpfs.

# Ответы на контрольные вопросы

1. **Какую информацию содержит учётная запись пользователя?**  
     
   - UID (идентификатор пользователя) и GID (идентификатор группы);  
   - Логин (username) и пароль (в зашифрованном виде хранится в /etc/shadow);  
   - Полное имя (GECOS);  
   - Путь к домашней директории (/home/trbessonov);  
   - Оболочка входа по умолчанию (/bin/bash).

   

2. **Команды терминала (примеры):**  
     
   - *Справка по команде:* `man ls` или `cp --help`.  
   - *Перемещение:* `cd /var/tmp`.  
   - *Просмотр содержимого каталога:* `ls -la /home`.  
   - *Определение объёма:* `du -sh /var/log`.  
   - *Создание / удаление:* `mkdir test_dir`, `rm -rf test_dir`, `touch file.txt`, `rm file.txt`.  
   - *Задание прав:* `chmod 755 script.sh`, `chown trbessonov:trbessonov script.sh`.  
   - *История команд:* `history`, просмотр последних 10: `history 10`.

   

3. **Что такое файловая система? Примеры с краткой характеристикой:** Файловая система — порядок и структура хранения, наименования и доступа к данным на носителе информации.  
     
   - **ext4:** традиционная журналируемая ФС Linux, отличается высокой надёжностью и совместимостью;  
   - **Btrfs:** современная ФС на основе принципа Copy-on-Write (CoW), поддерживает снапшоты, объединение накопителей и сжатие на лету;  
   - **XFS:** высокопроизводительная 64-битная журналируемая ФС, отлично масштабируется для работы с большими файлами;  
   - **FAT32 / exFAT:** универсальные файловые системы без разграничения прав доступа POSIX, применяемые на сменных Flash-накопителях.

   

4. **Как посмотреть, какие файловые системы подмонтированы в ОС?** С помощью команд `findmnt`, `df -hT` или вывода содержимого системного файла `cat /proc/mounts`.  
     
5. **Как удалить зависший процесс?** Найти PID процесса через `ps aux | grep имя` или `pgrep имя`, после чего отправить сигнал завершения:  
     
   - Мягкое завершение (SIGTERM): `kill <PID>`;  
   - Принудительное аварийное завершение (SIGKILL): `kill -9 <PID>` или `killall -9 <имя_процесса>`.
