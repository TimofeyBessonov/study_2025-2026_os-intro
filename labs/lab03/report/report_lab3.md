## **1\. Освоение синтаксиса Markdown и формул**

В процессе выполнения работы были изучены основные синтаксические конструкции Markdown:

> * Стилизация текста: выделение полужирным \*\*текст\*\*, курсивом \*текст\*, полужирным курсивом \*\*\*текст\*\*\*;  
> * Списки: упорядоченные и маркированные списки с поддержкой уровней вложенности;  
> * Блоки кода и цитирование через знак \>;

  * Внутритекстовые формулы: \\sin^2(x) \+ \\cos^2(x) \= 1;  
  * Выключные формулы с идентификаторами для перекрёстных ссылок:

\\sin^2(x) \+ \\cos^2(x) \= 1

## **2\. Настройка автоматической сборки через Makefile**

В каталоге с отчётом был создан файл Makefile для автоматизации генерации документов с помощью pandoc и фильтра pandoc-crossref:  
`FILES = $(patsubst %.md, %.docx, $(wildcard *.md))`  
`FILES += $(patsubst %.md, %.pdf, $(wildcard *.md))`

`LATEX_FORMAT =`   
`FILTER = --filter pandoc-crossref`

`all: $(FILES)`  
	`@echo $(FILES)`

`%.docx: %.md`  
	`-pandoc "$<" $(FILTER) -o "$@"`

`%.pdf: %.md`  
	`-pandoc "$<" $(LATEX_FORMAT) $(FILTER) -o "$@"`

`clean:`  
	`-rm -f $(FILES) *~`
