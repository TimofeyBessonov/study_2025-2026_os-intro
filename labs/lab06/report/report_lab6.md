# **Ответы на контрольные вопросы**

> 1. **Что такое командная строка?** Командная строка (CLI) — это текстовый интерфейс взаимодействия пользователя с операционной системой, в котором управление осуществляется путем ввода строковых инструкций с клавиатуры и получения текстового ответа от интерпретатора команд (shell).  
> 2. **При помощи какой команды можно определить абсолютный путь текущего каталога? Приведите пример.** С помощью команды pwd (print working directory). *Пример:*  
>    `pwd`  
>    `# Вывод: /home/trbessonov/work`  
>    ```` ```[span_76](start_span)[span_76](end_span) ````

> 3. **При помощи какой команды и каких опций можно определить только тип файлов и их имена в текущем каталоге? Приведите примеры.** С помощью команды ls \-F (или ls \--classify). При ее использовании к именам файлов дописывается специальный символ-идентификатор: / для директорий, \* для исполняемых файлов, @ для символических ссылок, \= для сокетов, | для FIFO-каналов. *Пример:* ls \-F.  
> 4. **Каким образом отобразить информацию о скрытых файлах? Приведите примеры.** Скрытые файлы в Linux начинаются с символа точки .. Для их отображения используется утилита ls с флагом \-a (--all) или \-A (--almost-all, скрывает сами ссылки . и ..). *Пример:* ls \-a \~.  
> 5. **При помощи каких команд можно удалить файл и каталог? Можно ли это сделать одной и той же командой? Приведите примеры.** Для файлов используется rm. Для пустых каталогов — rmdir. Одной и той же командой удалить и файл, и каталог можно с помощью rm с рекурсивным ключом \-r (или \-rf):  
   * Файл: rm document.txt;  
   * Каталог: rm \-r project\_folder.  
> 6. **Каким образом можно вывести информацию о последних выполненных пользователем командах?** С помощью встроенной команды history. Для вывода фиксированного числа последних команд можно передать число: например, history 15\.  
> 7. **Как воспользоваться историей команд для их модифицированного выполнения? Приведите примеры.** Используется синтаксис \!\<номер\>:s/\<старое\>/\<новое\> (заменяет первое вхождение) или \!\<номер\>:gs/\<старое\>/\<новое\> (заменяет все вхождения). *Пример:* Если под номером 42 была команда ls \-l /var, то \!42:s/var/tmp выполнит ls \-l /tmp.  
> 8. **Приведите примеры запуска нескольких команд в одной строке.**  
   * Последовательный безусловный запуск (разделитель ;): cd /tmp; ls \-la; pwd;  
   * Запуск только при успешном завершении предыдущей (&&): mkdir test && cd test;  
   * Запуск при ошибке предыдущей (||): cd folder || mkdir folder.  
> 9. **Дайте определение и приведите примеры символов экранирования.** Экранирование — это отмена специального значения служебного символа для интерпретатора Shell, превращающая его в обычный текстовый символ. Основным символом экранирования является обратный слэш \\. Также используется экранирование одинарными '...' и двойными "..." кавычками. *Пример:* создание файла с пробелом в имени: touch my\\ file.txt или поиск спецсимвола: grep \\\* file.txt.  
> 10. **Охарактеризуйте вывод информации на экран после выполнения команды ls с опцией \-l.** Команда выводит подробный листинг в виде колонок:  
    1. Тип файла и биты прав доступа (например, drwxr-xr-x);  
    2. Количество жестких ссылок;  
    3. Имя владельца файла;  
    4. Имя группы владельца;  
    5. Размер файла в байтах;  
    6. Дата и время последней модификации;  
    7. Имя файла или подкаталога (для ссылок указывается целевой путь через \-\>).  
> 11. **Что такое относительный путь к файлу? Приведите примеры использования относительного и абсолютного пути.**  
    * **Абсолютный путь:** путь к объекту от самого корня файловой системы / (всегда начинается со слэша /). *Пример:* cd /var/log/nginx/.  
    * **Относительный путь:** путь к объекту относительно текущего рабочего каталога (использует обозначения . для текущей папки и .. для родительской). *Пример:* cd ../../etc.  
> 12. **Как получить информацию об интересующей вас команде?**  
    * Через развернутую системную справочную страницу: man \<имя\_команды\>;  
    * Через краткую встроенную справку утилиты: \<имя\_команды\> \--help или \<команда\> \-h;  
    * Для встроенных команд Bash: help \<команда\>.  
> 13. **Какая клавиша или комбинация клавиш служит для автоматического дополнения вводимых команд?** Клавиша Tab. Одиночное нажатие дополняет уникальное имя команды или пути к файлу; двойное быстрое нажатие (Tab Tab) выводит список всех доступных вариантов, если соответствий несколько.
